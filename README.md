# open-science-glossary

Public Open Science glossary accompanying the seminar **Introduction to Open Science** (Universitaet Hamburg, Winter Semester 2026/27), developed from v1.0.0 ([DOI 10.5281/zenodo.23449750](https://doi.org/10.5281/zenodo.23449750)).

Status: **planning**. Nothing is built yet. The planning documents (concept, data model, architecture, roadmap, ADRs, open questions) live under `docs/` and are being reviewed in a pull request on the `planning/concept` branch.

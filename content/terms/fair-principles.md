A set of data management principles (Wilkinson et al., 2016) stating that research data should be: G

## Details

- Findable; assigned a persistent identifier (e.g. DOI) and rich metadata for discoverability
- Accessible; retrievable via a standard protocol; access conditions clearly stated
- Interoperable; using shared, open standards and vocabularies that allow data from different sources to work together
- Reusable; described with sufficient provenance and context, and released under a clear licence

> [!WARNING]
> FAIR ≠ Open: data can be fully FAIR while still access-restricted for legitimate reasons (privacy, sensitivity, Indigenous governance). The principle is “as open as possible, as closed as necessary”

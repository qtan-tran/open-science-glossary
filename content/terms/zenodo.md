A general-purpose, open access repository hosted by CERN (Geneva) and developed through the OpenAIRE project funded by the European Commission. Launched in 2013.

## Details

- Free to use: accepts any file type, any research discipline
- Mints DataCite DOIs automatically for every deposit
- Storage limit: 50GB per record (free tier)
- Integrates with ORCID, GitHub (for software versioning), and OpenAIRE
- Versioned deposits: each update creates a new DOI while a “concept DOI” always points to the latest version
- A first-choice repository for data, code, presentations, posters, preprints, and outputs without a dedicated subject repository
